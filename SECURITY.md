# Security

## Reporting a vulnerability

If you discover a security issue in **veloz-stack** (CLI, template generator, or web app), please report it privately rather than opening a public issue with exploit details.

1. Email or message the maintainers through your usual Veloz / repository contact channel.
2. Include steps to reproduce, affected versions, and impact if known.
3. Allow reasonable time for a fix before public disclosure.

We will acknowledge receipt and coordinate a fix and release when appropriate.

## Scope

- This repository: scaffold generator, stack validation, and the stack builder site.
- **Generated projects** are owned by whoever runs the CLI; apply your own security process to apps you scaffold.

## Supported versions

Security fixes are applied on the default branch (`main`). Use the latest release of `create-veloz-stack` when publishing or deploying.
