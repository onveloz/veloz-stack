# create-veloz-stack

CLI that scaffolds projects from `@veloz-stack/template-generator`.

## Develop

From repo root:

```bash
pnpm dev:cli
# or: pnpm --filter create-veloz-stack dev
```

## Build and link locally

```bash
pnpm cli:link
create-veloz-stack my-app
```

## Package

Published as `create-veloz-stack` (MIT). Build output: `dist/index.mjs`.
